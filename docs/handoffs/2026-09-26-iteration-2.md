## Gotchas learned tonight (worth keeping)

- **Merging needs an in-session go-ahead.** The auto-mode classifier refuses `gh pr merge` ("Merge Without Review") when the go-ahead exists only in a handoff doc. Ask Erik once in the session for a standing go-ahead on green, reviewed PRs.
- **Where the open-pr marker can go.** Writing the open-pr gate's marker into a worktree's git dir was refused as a bypass; the skill's documented marker at the worktree's top level (`.open-pr-analysis.json`, written with literal values in its own Bash call) works. Delete it after `gh pr create`.
- **Subagent report files.** Subagents often can't Write report files; have them return the report in the message, and relay it to a file yourself.
- **Merging back to back.** GitHub keeps one pending deploy per concurrency group, so merging several PRs quickly deploys only the last. That's harmless here, since the last deploy contains all of them.
- **The Vite dev proxy is hard-coded:** it sends `/api` to `localhost:3001`. A private stack for the tour or a preview must put the backend on 3001 and set `BACKEND_URL`.
- **Keep tests off `kriket-pg`'s `app_test` in parallel runs.** Backend tests and the Playwright setup both truncate it: run backend tests one at a time behind a lock, and e2e only in CI or in a private container.
