# What was published at 26.cohack.tetl.ca

An exact copy of every file on the hackathon kit's site (https://26.cohack.tetl.ca), taken on 2026-09-28 before the kit's AWS resources were deleted. The site was served from an S3 bucket behind CloudFront; once those are gone, this folder is the only copy of the pages that were built outside git.

Pages linked with absolute paths (`/tour/`, `/assets/...`), so view them through a local web server rather than by opening the files:

```
cd docs/published/26.cohack.tetl.ca && python3 -m http.server 8000
```

then open http://localhost:8000/kriket/.

## What is here

| Path | What it is | Source in a repo |
|---|---|---|
| `kriket/` | The team index | `tools/pages/index.html` |
| `kriket/board/` | The iteration 2 build board | none; built outside git |
| `kriket/qwen/` | The Qwen experiment: the same iteration 2 plan built by the kit's open-weight model, with every run and what the checks found | none; built outside git |
| `board/` | The iteration 1 build board | `tools/pages/board.html` |
| `tour/`, `tour/2/` | The app tour after iteration 2 (the same page) | built by `tools/tour/`; the screenshots are embedded, not in git |
| `tour/1/` | The app tour after iteration 1 | built by `tools/tour/`; screenshots embedded |
| `tour/2-proposal/` | The proposed prototype for iteration 2, and its clickable `app.html` | built by `tools/tour-proposal/` |
| everything else (`index.html`, `runbook/`, `team-kit/`, `assets/`, `search/`, `404.html`, `sitemap.xml`) | The hackathon kit's own docs site, generated by MkDocs | the kit repo, https://github.com/ert485/xenia-2026 |

Nothing in these pages is private: every one of them was leak-checked before it was uploaded.
