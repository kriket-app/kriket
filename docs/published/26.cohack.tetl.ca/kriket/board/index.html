        How it runs

        Two tracks, one plan. The tasks on this board are the Claude track, which ships: Claude agents build each task in their own branch, then make check, the backend tests, the kit's verifier, a reviewer, and CI decide whether it is done, never the agent's own report. One PR per task, merged by hand when green; every merge deploys.

        At the same time, the Qwen track builds the same plan as an experiment: agents on the kit's team model (Qwen3 Coder on the GPU box) inside the kit's dev container, with a default-deny firewall and no credentials, gated by the same checks. It never merges. The experiment page shows how far it gets, and the two are compared at the end.

        Nothing on this page is private. Times are Saskatoon time (CST).
